# PHAOS-RESPONSE-001 — interpretation and response guidance

`UTILITY-05` adds an action-oriented metadata layer without turning an indicator, target or observed signal into an automatic instruction.

## Governing distinction

- **Source-stated protocol:** allowed only with an exact official SOP/guideline, version and locator.
- **Analyst-advisory workflow:** a transparent review sequence that verifies data, interprets context and refers a persistent signal to the responsible reviewer.
- **Unavailable:** no governed guidance is asserted; this is not evidence that no external protocol exists.

The 30-record pilot reuses the balanced `UTILITY-03` sample. Its cited indicator sources do not contain sufficiently precise response protocols for these manifestations, so the release publishes zero official protocols and 30 analyst-advisory review workflows. This is a deliberate evidence result, not a missing-data workaround.

## Safety boundary

Guidance does not assess observed values, prescribe clinical care, establish alerts, authorize sanctions or replace national, state, district, facility or emergency protocols. Targets remain separate reference-value records. Public bulk-download controls remain disabled.

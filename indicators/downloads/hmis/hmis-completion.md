# HMIS linked knowledge registry — Release 1.3

Cut-off: 2026-09-01

This release promotes 54 historical formula-defined indicators into the main registry and connects them to a separate HMIS knowledge structure containing 700 April-2025 data-element labels, 202 historical OGD outputs and 25 historical validation relationships.

The structure is public-source-bounded. It is not presented as the complete live national HMIS dictionary. Crosswalk candidates are analytically generated and labelled pending custodian validation.

Current public forms, historical formulas and historical outputs remain explicitly versioned and separated.
